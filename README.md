# Computer-Vision-Inference-Service
A production-oriented computer vision service for image classification or object detection using deep learning models. The project covers dataset preparation, image preprocessing, augmentation, transfer learning, model training, and evaluation using task-appropriate metrics such as precision, recall, F1 score, and mean average precision.

The trained model is exposed through a REST API supporting image uploads, batch predictions, and structured inference responses. The service includes model versioning, input validation, performance profiling, automated testing, and Docker packaging to demonstrate how computer vision models can be integrated into reliable software applications.
